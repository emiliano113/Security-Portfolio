# 🛡️ Security Portfolio

Repositorio donde documento mi progreso en seguridad ofensiva, resolviendo 
laboratorios prácticos de [PortSwigger Web Security Academy](https://portswigger.net/web-security) 
y desafíos de [picoCTF](https://picoctf.org/).

Soy estudiante de Ingeniería en Sistemas (3er año) profundizando en seguridad 
web por cuenta propia. Cada write-up explica la vulnerabilidad trabajada, el 
razonamiento para encontrarla y cómo la exploté, en mis propias palabras.
